# Sprint 1 — Production Foundation

**Status: Completed and frozen**

## Goal

Establish a secure production foundation for the NIT3004 four-week engineering
studio and prove the core student submission and teacher summary workflows.

## Delivered scope

- React, Vite and TypeScript student portal
- Supabase PostgreSQL integration, grants and Row Level Security
- Week 1 Check-in, Class Pulse, Team Conversation and Four-Week Promise
- Week 3 Poster Peer Review data model and validation
- Teacher authentication and teacher-only summary dashboard
- Vercel production deployment from GitHub `main`
- Student-friendly validation, duplicate protection and read-only
  same-browser receipts
- Temporarily disabled Peer Review student entry point pending the formal
  Sprint 2 control

This plan is a historical record. New behaviour or changed requirements must be
planned in a later Sprint.
