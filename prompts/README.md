# Session Prompts

This directory contains the stable protocol for starting a new AI-assisted work
session.

Use [START_SESSION.md](START_SESSION.md) for every session. Do not create a new
prompt for each Sprint or Phase. Plans, progress and decisions belong in
`docs/sprints`; source code and merged Git history remain the final authority.

## Short prompts for ChatGPT Work

Continue the current Sprint:

```text
Read the latest `main` from GitHub repository
`GongqiLinVU/milestoneproject` and continue according to
`prompts/START_SESSION.md`.
```

Review a named Sprint:

```text
Read the latest `main` from GitHub repository
`GongqiLinVU/milestoneproject` and, according to
`prompts/START_SESSION.md`, review Sprint 2 and prepare the next step.
```
